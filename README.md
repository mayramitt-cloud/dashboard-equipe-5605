## 📋 O que é?

Sistema de acompanhamento dos casos clínicos discutidos nas reuniões semanais da equipe, com:
- Importação automática de dados do Microsoft Forms (das ACS)
- Visualização de casos por linha de cuidado
- Marcação de urgências
- Acompanhamento de visitas domiciliares

## 📥 Como usar

### 1. **Preenchimento do Formulário** (ACS)
As agentes comunitárias preenchem o formulário no **Microsoft Forms** com os dados do caso.

### 2. **Importar no Dashboard**
Na reunião:
- Microsoft Forms → **Respostas**
- Abrir no Excel
- Arquivo → Salvar como → Baixar (.xlsx)
- No dashboard → **📥 Importar respostas do Forms**

### 3. **Visualizar e Discutir**
Os casos aparecem organizados por:
- Linha de cuidado
- ACS responsável
- Status de urgência
- Necessidades identificadas
